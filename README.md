This repository preserves the canonical first-generation implementation of PREP-KC’s **8th Grade Data in Action** course, framed under the NC3 Trane supplementary curriculum initiative in Fall 2023.

---

## 1. The 3-Module Epistemological Architecture

Rather than treating data education merely as software tool training (e.g. clicking buttons in Tableau), the course structured data science as an investigative, historical, and decision-making discipline:

```text
MODULE 1: WHY DATA? (Context & Foundations)
• Data in History: Florence Nightingale (polar area diagram), Charles Minard (Napoleon's march), William Playfair.
• Modern Data Collection & Big Data Evolution.
• Epistemic Coin Toss Game (module1/coingame.html): Interactive coin-flip sampling testing evidence sufficiency.

                     │
                     ▼
MODULE 2: REASONING WITH DATA (Critical Thinking & Tradeoffs)
• Data Quality, Missing Data, and Anomaly Detection.
• Interactive Scale of Data (module2/scale_of_data.html): Byte ──> Zettabyte exploration.
• Speed vs. Accuracy Tradeoffs (module2/accuracy_vs_speed.html).

                     │
                     ▼
MODULE 3: APPLIED VISUALIZATION (Tableau & Design Process)
• Core Tableau Concepts, Visual Hierarchies, and Chart Types.
• Dashboard Architecture, Audience Scoping, and Interactivity.
• Iterative Design Review Process (module3/process.html).
```
